# React Counter Program

## 📌 About the Project

This is a simple Counter Application developed using React.js. It allows users to increase, decrease, and reset the counter value with the help of interactive buttons.

## 🚀 Features

* **Increment:** Increases the counter value by 1.
* **Decrement:** Decreases the counter value by 1.
* **Reset:** Resets the counter value to 0.
* **Interactive UI:** Updates the counter value dynamically.

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS

## 💻 How to Run the Project

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Install the required dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in the terminal.
